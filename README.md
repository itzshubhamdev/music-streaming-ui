# Music Streaming UI

A static web interface for a music streaming platform built with HTML and CSS.

## Components

- Sidebar Navigation
- Header
- Main Content Area
- Music Player (Footer)

## Technologies Used

- HTML5
- CSS3
- Lucide Icons

## Project Structure

```
├── index.html     # Main HTML structure of the UI
├── library.html   # Library page of the UI
├── playlists.html # Playlists page of the UI
├── styles.css     # Stylesheet for layout and design
└── images/        # Directory containing placeholder cover art and assets
```

## AI Usage

- **Design**: Google Stitch
- **Images**: Google Gemini (Nano Banana)
